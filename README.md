# Final Year Placement Preparation Platform

A clean student-friendly React + Vite frontend for placement preparation.

## Tech Stack

- React + Vite
- Tailwind CSS
- React Router DOM
- Axios

## Run

```bash
npm install
npm run dev
```

The frontend expects backend APIs under `http://localhost:8080/api`.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal > Run Task.
3. Choose `Run Frontend`.
4. Open `http://localhost:5173`.

Recommended VS Code extensions are listed in `.vscode/extensions.json`.
